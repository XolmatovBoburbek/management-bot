# IAC PM — Telegram-бот и Mini App для управления проектами

Бот для команды IAC Media: берёт ERP-таблицу проекта (Excel или Google Таблицу), раздаёт задачи ответственным,
каждый день напоминает о сроках, спрашивает «выполнили?», собирает список обзвона и показывает руководителю,
где горит. Бот работает в личке и в рабочей группе, а Mini App служит личным кабинетом и админ-панелью.

Бот: **[@iacpmbot](https://t.me/iacpmbot)**

## Что умеет

**Каждому участнику (в личку)**
- Утром (09:00): задачи на сегодня, просроченные и ближайшие. По каждой горящей задаче отдельно приходит вопрос
  **«Выполнили?»** с кнопками «✅ Да», «⏳ Ещё в работе» (бот спросит, когда будет готово) и «🆘 Нужна помощь».
- Вечером (18:00): «Завтра срок. Успеваете?» с кнопками «👍 Успеваю», «✅ Уже готово» и «🆘 Нужна помощь».
- По понедельникам приходит обзор задач без срока.
- Когда назначают новую задачу, приходит уведомление с кнопками «В работу», «Выполнено», «Проблема» и «Комментарий».
- **Личный кабинет** (кнопка «Открыть» в чате с ботом): свои задачи по срокам, прогресс, история, комментарии.

**Руководителю / PM (Азмиддин, Шахзод)**
- 09:30: сводка по проекту (просрочки, блокеры, что закрыто за сутки, что дозаполнить в таблице) и число контактов
  в обзвоне.
- «🆘 Нужна помощь» от любого участника сразу приходит PM с кнопкой «Написать».
- **Обзвон**: бот сам составляет список на день: кому из команды позвонить (просрочки, «нужна помощь», срок сегодня
  или завтра, а работа не начата), каких подрядчиков дёрнуть по ближайшим задачам и кто ещё не подключился к боту.
  Звонки отмечаются галочкой. Можно запланировать звонок на время («📞 Пора позвонить…» с кнопками «Созвонился»,
  «Через час» и «Завтра»).
- **Панель** (вкладка ⚙️ в Mini App): создать проект, завести или отредактировать задачу, загрузить Excel, подключить
  Google Таблицу, выгрузить актуальный Excel в чат, настроить время напоминаний, управлять командой.
- **Черновик сроков**: если в таблице дедлайны не заполнены («Уточнить»), бот предложит их обратным отсчётом от даты
  мероприятия (KV за 18 дней, производство за 10, монтаж в T-1, отчёт в T+7…) и разнесёт так, чтобы у одного
  человека было не больше 3 дедлайнов в день. Применяются только отмеченные галочкой.
- **Проверка таблицы**: не указана дата мероприятия, задачи без срока или ответственного, имя не из команды,
  перегруженные люди, участники без задач.

**В рабочей группе** (добавьте бота и отправьте `/bind_group`)
- Ежедневная сводка с упоминаниями тех, у кого просрочки.
- «✅ @ник закрыл(а) задачу», «🆘 @ник: нужна помощь…».
- Команды `/summary`, `/add`, `/my` (ответ придёт в личку).

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | подключиться (бот узнаёт человека по нику из списка команды) |
| `/my` | все | мои задачи и сроки |
| `/summary` | все | сводка по проекту |
| `/calls` | все | обзвон на сегодня |
| `/add @ник 30.09 Название` | админы | быстро добавить задачу (`!!` — критично, `!` — высокий) |
| файл `.xlsx` в личку | админы | загрузить или обновить задачи |
| `/sheet ссылка` | админы | подключить Google Таблицу |
| `/sync` | админы | синхронизировать с Google Таблицей сейчас |
| `/export` | админы | получить актуальный Excel |
| `/bind_group` | админы | присылать сводки в эту группу |

## Команда

Список команды загружается из [`config/team.yaml`](config/team.yaml) при первом запуске, дальше им удобнее управлять
в Mini App → Панель → Команда. Бот узнаёт человека по Telegram-нику, поэтому **каждый должен один раз нажать Start**
в личке с ботом: иначе Telegram не даст боту написать ему первым. Кто ещё не подключился, видно в Панели и в обзвоне.

Имя в колонке «Ответственный» должно совпадать с именем в команде. Другие написания (латиница, с фамилией)
добавляются в поле «Другие написания». Если ответственных несколько, их пишут через `/` или запятую
(«Сарвар / Сардор»).

## Таблица задач

Бот ищет колонки по заголовкам, а не по буквам, поэтому таблицу можно дорабатывать. Обязательны только
**«Процедура»** (или «Задача») и **«Ответственный»**. Остальные колонки необязательны: «Блок», «Что конкретно
сделать», «Приоритет», «Статус процедуры», «Начало работы», «Окончание работы», «Фактическая дата завершения»,
«Поставщик / Исполнитель», «Доказательство выполнения», «Комментарии исполнителя». Также читаются листы
«Информация о проекте» (название, код, дата мероприятия), «MILESTONE» и «Risk list».

Даты можно писать как `25.10.2026`, `25.10`, `25 октября` или относительно мероприятия: `T-3`, `T`, `T+1`.
Значение «Уточнить» считается пустой датой.

**Повторная загрузка не затирает работу в боте.** Если поле изменили в таблице, берётся значение из таблицы. Если
в таблице оно осталось прежним, сохраняется то, что отметили в боте. Задачи, созданные в боте, при выгрузке Excel
дописываются в конец листа.

### Google Таблица

1. В таблице: «Настройки доступа» → «Все, у кого есть ссылка» → **Читатель**.
2. Боту: `/sheet https://docs.google.com/spreadsheets/d/…` (или Панель → Google Таблица).
3. Бот забирает изменения каждые 10 минут (настраивается).

Чтобы статусы, даты и комментарии из бота **записывались обратно в Google Таблицу**, нужен сервисный аккаунт Google:
Google Cloud Console → IAM → Service Accounts → создать → Keys → Add key → JSON. Файл положите в
`secrets/google.json`, в `.env` добавьте `GOOGLE_CREDENTIALS_FILE=/secrets/google.json`, а в таблице выдайте
адресу `…@….iam.gserviceaccount.com` доступ **Редактор**. Также включите Google Sheets API и Google Drive API
для проекта. Без этого бот работает в режиме «только чтение», а актуальный Excel выгружается командой `/export`.

## Развёртывание на Azure

Mini App требует публичный **HTTPS**-адрес. Бот работает через long polling, входящие вебхуки не нужны.
Запускайте **ровно один** экземпляр бота с этим токеном, иначе Telegram вернёт ошибку `terminated by other getUpdates`.

### Вариант A: та же виртуальная машина, где работает другой бот (рекомендуется)

1. **Домен.** Azure Portal → ваша VM → Public IP address → Configuration → **DNS name label**, например `iacpm`.
   Получится `iacpm.<регион>.cloudapp.azure.com`. Если метка уже есть, используйте её.
2. **Порты.** VM → Networking → Add inbound port rule: **80** и **443** (TCP). Через Azure CLI:
   ```bash
   az vm open-port -g <resource-group> -n <vm-name> --port 80 --priority 1010
   az vm open-port -g <resource-group> -n <vm-name> --port 443 --priority 1020
   az network public-ip update -g <resource-group> -n <public-ip-name> --dns-name iacpm
   ```
3. **Установка** (по SSH на VM):
   ```bash
   git clone https://github.com/XolmatovBoburbek/management-bot.git
   cd management-bot
   bash deploy/azure/setup-vm.sh
   ```
   Скрипт установит Docker, спросит токен и домен, создаст `.env` и запустит бота вместе с Caddy (HTTPS-сертификат
   выпускается автоматически). Если порты 80/443 уже заняты веб-сервером другого бота, скрипт поднимет только этого
   бота на `127.0.0.1:8080` и напечатает готовый блок для nginx.
4. Проверка: `https://<домен>/health` возвращает `{"ok": true}`. В Telegram у бота появится кнопка «Открыть».

Обновление: `git pull && docker compose up -d --build`. Логи: `docker compose logs -f bot`.
Данные (база SQLite и загруженные таблицы) лежат в docker-томе `bot-data`. Бэкап:
`docker compose cp bot:/data ./backup`.

### Вариант B: Azure App Service (Linux, Python)

```bash
az webapp up -g <resource-group> -n iacpm-bot --runtime "PYTHON:3.11" --sku B1
az webapp config appsettings set -g <resource-group> -n iacpm-bot --settings \
  BOT_TOKEN=<токен> WEBAPP_URL=https://iacpm-bot.azurewebsites.net DATA_DIR=/home/data \
  TIMEZONE=Asia/Tashkent PORT=8000 WEBSITES_PORT=8000 SCM_DO_BUILD_DURING_DEPLOYMENT=true
az webapp config set -g <resource-group> -n iacpm-bot --always-on true --startup-file "python -m app.main"
```
HTTPS-адрес `*.azurewebsites.net` выдаётся автоматически. Нужен тариф с Always On (B1 и выше) и один инстанс
(без автомасштабирования). `/home` в App Service постоянный, поэтому база переживает перезапуски.

### Другой сервер

Подойдёт любой Linux с Docker: заполните `.env` по образцу [`.env.example`](.env.example) и выполните
`docker compose up -d --build`. Для быстрой проверки без домена подойдёт туннель
`cloudflared tunnel --url http://localhost:8080`: полученный https-адрес пропишите в `WEBAPP_URL`.

## Настройки (`.env`)

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `WEBAPP_URL` | публичный https-адрес Mini App |
| `DOMAIN` | домен для Caddy в docker-compose |
| `TIMEZONE` | часовой пояс напоминаний, по умолчанию `Asia/Tashkent` |
| `GOOGLE_CREDENTIALS_FILE` | JSON сервисного аккаунта Google (необязательно) |
| `DATA_DIR` | где хранить базу и файлы (в Docker — `/data`) |

Время рассылок, число вопросов «выполнили?» в день, день недельного обзора, время статус-созвона и частота
синхронизации настраиваются в Mini App → Панель → Напоминания.

## Разработка

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest                                       # тесты
DEV_AUTH_USERNAME=s_maxhan python scripts/dev_server.py path/to/table.xlsx   # Mini App в браузере без Telegram
```

Структура:
- `app/excel_io.py`: чтение таблиц и выгрузка Excel;
- `app/db.py`: SQLite, импорт с трёхсторонним слиянием;
- `app/logic.py`: сроки, нагрузка, обзвон, проверка таблицы, черновик сроков;
- `app/service.py`: действия и уведомления (общие для бота, Mini App и планировщика);
- `app/scheduler.py`: ежеминутный планировщик рассылок (без дублей и пропусков при перезапуске);
- `app/bot.py`: команды и кнопки Telegram;
- `app/web.py` и `webapp/`: API и интерфейс Mini App (проверка подписи `initData` от Telegram).
